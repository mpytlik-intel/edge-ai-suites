# Wind Turbine Anomaly Detection Sample App

Wind turbine anomaly detection sample app demonstrates a time series use case
by detecting anomalous power generation patterns in wind turbines, relative to wind
speed. By identifying deviations, it helps optimize maintenance schedules and prevent
potential turbine failures, enhancing operational efficiency.
