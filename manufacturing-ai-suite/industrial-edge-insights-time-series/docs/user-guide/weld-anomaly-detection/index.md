# Weld Anomaly Detection Sample App

Weld Anomaly Detection sample app demonstrates how AI-driven analytics enable
edge devices to monitor weld quality. They detect anomalous weld patterns and
alert operators for timely intervention, ensuring proactive maintenance, safety,
and operational efficiency. No more failures or unplanned downtime.
